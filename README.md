# PicLink-Ads

Công cụ tạo thẻ quảng cáo hình ảnh Facebook (Facebook Link Card & Open Graph Preview Generator).

## Tính năng chính
- **Card đầy đủ:** Tự động tạo thẻ xem trước Facebook bao gồm Ảnh bìa (1200x630px), Tiêu đề, Mô tả và Link đích.
- **Ảnh sạch (Clean Image Mode):** Tự động ẩn Tiêu đề & Mô tả trên Facebook, giúp tạo trải nghiệm thẻ ảnh siêu sạch cuốn hút lượt nhấp.
- **Tạo link ngắn tùy chỉnh:** Hỗ trợ tùy chỉnh slug ngắn (`/c/your-slug`).
- **Live Preview:** Xem trước giao diện bài đăng Facebook chuẩn xác theo thời gian thực.

## Cài đặt & Chạy ứng dụng

```bash
# Cài đặt dependencies
npm install

# Chạy ở chế độ Development
npm run dev
# hoặc: make dev
```

Ứng dụng sẽ chạy tại `http://localhost:3000`.

## Công nghệ sử dụng
- **Next.js 14+ / React**
- **TypeScript**
- **SQLite**
- **Vanilla CSS / Modern Glassmorphism UI**
